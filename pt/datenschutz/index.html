2. Recolha e tratamento de dados pessoais

(1) Visita do site: Ao visitar o meu site, são recolhidos automaticamente determinados dados que o seu navegador transmite ao servidor. Estes dados (por exemplo, endereço IP, data e hora do acesso, tipo de navegador, sistema operativo, página visitada) são tratados exclusivamente para garantir um funcionamento sem problemas e melhorar os meus serviços. A base jurídica é o Art. 6.º, n.º 1, alínea f) do RGPD (interesse legítimo).

(2) Formulário de contacto: Se utilizar o formulário de contacto, os dados que introduzir (nome, endereço de e-mail, mensagem) serão armazenados para o efeito de processar o seu pedido e para eventuais perguntas subsequentes. A base jurídica é o Art. 6.º, n.º 1, alínea b) do RGPD (execução do contrato) ou o Art. 6.º, n.º 1, alínea f) do RGPD (interesse legítimo em responder ao seu pedido).

(3) Marcação de reuniões: Para a marcação de reuniões, utilizo o serviço Zoho Calendar. Ao marcar uma reunião, os dados que fornece (nome, e-mail, pedido de reunião) são transmitidos e tratados pela Zoho. Para mais informações, consulte a política de privacidade da Zoho.

3. Comunicação de dados a terceiros

Os seus dados pessoais só serão comunicados a terceiros se tal for necessário para a execução do contrato, se tiver dado o seu consentimento expresso ou se existir uma obrigação legal.

São utilizados os seguintes prestadores de serviços:

  • Formspree (processamento de formulários) – servidores nos EUA, cláusulas contratuais-tipo em conformidade com o RGPD
  • Zoho Corporation (marcação de reuniões) – servidores na UE, em conformidade com o RGPD
  • Google Analytics (análise web, anonimizada) – servidores em todo o mundo, cláusulas contratuais-tipo em conformidade com o RGPD

4. Cookies

Este site utiliza apenas cookies tecnicamente necessários. Por conseguinte, não é necessário consentimento para o armazenamento de cookies, desde que não sejam utilizados cookies de análise ou marketing. O Google Analytics é operado com a anonimização de IP ativada.

5. Duração do armazenamento

Os dados pessoais são armazenados apenas durante o tempo necessário para cumprir os respetivos fins. No caso de uma relação comercial, os dados são conservados de acordo com os prazos legais de conservação (na Áustria, geralmente 7 anos).

6. Os seus direitos

Tem o direito, em qualquer momento, a:

  • Acesso aos dados armazenados sobre si (Art. 15.º RGPD)
  • Retificação de dados incorretos (Art. 16.º RGPD)
  • Apagamento dos seus dados (Art. 17.º RGPD)
  • Limitação do tratamento (Art. 18.º RGPD)
  • Portabilidade dos dados (Art. 20.º RGPD)
  • Oposição ao tratamento (Art. 21.º RGPD)

Para exercer os seus direitos, contacte: info@felipeborecki.com

7. Direito de reclamação

Se considerar que o tratamento dos seus dados pessoais viola o RGPD, tem o direito de apresentar uma reclamação junto da autoridade de controlo. Na Áustria, esta é a Autoridade de Proteção de Dados (Barichgasse 40-42, 1030 Viena, www.dsb.gv.at).

8. Alterações a esta política

Reservo-me o direito de adaptar esta política de privacidade para refletir alterações nos requisitos legais ou nos meus serviços. Aplica-se a versão atual publicada nesta página.
